# 한 문제씩 · LeetCode 650

하루 1~2문제씩 공부하는 개인 학습 웹. Kotlin 입문부터 Easy 200 / Medium 400 / Hard 50을 기록합니다.

## 실행

```sh
npm install
npm start
```

http://localhost:4173 에서 사용합니다. Python 3와 Node.js가 필요합니다. 웹 자체는 HTML/CSS/JavaScript로 동작하며 서버 데이터베이스는 없습니다.

## 기능

- 서울 날짜 기준 오늘의 문제 1~2개, 미완료 문제 이어 풀기
- 풀이 상태(혼자 / 힌트 / 해설 / 미완료), 메모, 풀이 이력
- 힌트·해설 3일 후, 혼자 풀이 7일 후 복습. 연속 독립 풀이 시 간격 증가
- 11개 단원, 문제 검색·난이도 필터, 중복 없는 완료 수
- JSON 백업·복원. 잘못된 백업은 기존 기록을 덮어쓰지 않음
- 저장된 데이터 손상 감지 시 자동 덮어쓰기 방지
- 모바일 대응, 키보드 조작, 기록 다이얼로그

## 커리큘럼

2026-10-25 LeetCode 실제 목록에서 무료 여부·제목·난이도·태그를 확인한 650개입니다. 첫 30개는 입문용으로 직접 순서를 정했습니다. 이후는 유형/난이도별 할당량을 채우도록 문제 번호순으로 선택한 **초기 목록**이며, 모든 문제의 교육적 순서를 개별 검수한 것은 아닙니다. Hard 50개는 기본 600개 후 오늘의 문제로 나오며, 커리큘럼에서는 언제든 열 수 있습니다.

실제 무료 문제 수에 맞춰 백트래킹 Easy 2개와 연결 리스트 Easy 3개를 수학/배열 단원으로 옮겼습니다. 전체 목표는 그대로입니다. SQL·셸 등 Kotlin 학습과 무관한 유형은 선정 태그에서 제외했습니다. 문제 본문·해설을 복제하지 않고 원문 링크만 제공합니다.

## 저장

진도는 해당 브라우저의 localStorage에 저장됩니다. 브라우저/기기/접속 주소가 달라지면 공유되지 않습니다. 사이트를 옮기기 전, 브라우저 데이터를 지우기 전에는 백업을 내려받으세요. 복원은 확인 후 기존 기록 전체를 교체합니다. 공개 저장소에는 개인 진도가 올라가지 않습니다.

## 검증

```sh
npm test
npm run lint
npm run build
# npm start 실행 중, Google Chrome 설치 환경에서
npm run test:browser
```

`lint`는 JavaScript 구문 검사입니다. 브라우저 테스트는 별도 임시 프로필을 사용하고 `/tmp/leetcode-*.png`에 스크린샷을 저장합니다. `dist/`는 정적 배포 산출물입니다. GitHub Pages 등 정적 호스팅에 올릴 수 있습니다.
